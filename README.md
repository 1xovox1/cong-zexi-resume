# 丛泽熙 · 个人简历网站

蓝白清爽风格的静态简历站，可部署到 GitHub Pages。

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
```

## 部署到 GitHub Pages

1. 在 GitHub 新建仓库（如 `cong-zexi-resume`）
2. 上传本文件夹全部内容
3. Settings → Pages → Source 选 **Deploy from a branch** → branch `main` → folder `/ (root)`
4. 访问：`https://1xovox1.github.io/cong-zexi-resume/`

## 页面结构

- `index.html` — 主页
- `capabilities/agent.html` — Agent 能力深度页
- `projects/` — 三个项目详情页
